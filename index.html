Wat is een API?


Een API (Application Programming Interface) is een manier waarop softwareprogramma's met elkaar kunnen communiceren.


Zie het als een ober in een restaurant. Jij geeft een bestelling door, de ober brengt deze naar de keuken en komt vervolgens terug met het resultaat.


Websites en apps gebruiken API's om gegevens op te halen van andere systemen.
